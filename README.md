# FitTrack Pro 🏋️‍♂️

**FitTrack Pro** is a role-based Gym Management System designed for Admins, Trainers, and Members. It enables seamless gym scheduling, equipment tracking, attendance management, and class booking functionalities.

---

## 🔑 User Roles

### 🛠 Admin
- Add/Edit/Delete users and trainers
- Manage classes and equipment
- View revenue and analytics
- Oversee system settings

### 🧑‍🏫 Trainer
- View class schedule
- Mark attendance for members
- Track member participation
- Manage assigned classes

### 🧍 Member
- View dashboard with membership details
- Book available classes
- Track attendance and membership expiry

---

## 🧰 Tech Stack

- **Frontend:** HTML5, Tailwind CSS, Bootstrap 5
- **Backend:** PHP 8
- **Database:** MySQL
- **Server:** XAMPP

---

## 🚀 Setup Instructions

1. Clone the repository:
```bash
git clone https://github.com/sujata458/fittrack-pro.git
```

2. Import the database:
   - Use the provided `.sql` file (if included)
   - Or manually create the schema via phpMyAdmin

3. Configure database credentials in `/includes/db_config.php`

4. Run locally using XAMPP or any PHP-supported local server:
```
http://localhost/fittrack-pro/
```

---

## 📂 Folder Structure

- `admin_*.php` – Admin dashboard files
- `trainer_*.php` – Trainer dashboard files
- `member_*.php` – Member portal
- `includes/` – Config, header, sidebar, footer
- `assets/` – CSS, JS, images
